# 羅爾迪亞之翼 v1.21 — 共通事件呼叫名稱修復包

## 問題

部分地圖事件使用「以名稱呼叫共通事件」的命令。中文版把**呼叫端的名稱字串**翻成了中文
（例如 `レーン1` → `蕾1`），但 `Data/BasicData/CommonEvent.dat` 裡的**定義名稱**仍是日文。
執行時 CALL 找不到對應名稱，WOLF 不會顯示錯誤，玩家看到的是「按確認鍵沒反應」。

本次玩家回報的哥魯德利亞酒場偵探事件，就是其中一例：
頁1呼叫 `蕾1`、頁2呼叫 `蕾3`、同地圖事件呼叫 `蕾5`，但名稱表只有 `レーン1/3/5`。

## 潛在錯誤統計

- 受影響：**18 張地圖、23 個呼叫點、18 個不同目標名稱**。
- 完整清單（檔案、呼叫序號、原版／現行名稱、位移）：[`受影響清單.md`](受影響清單.md)。
- 這 23 個的共同特徵：現行名稱不存在於名稱表，但原版對照 `Data/MapData - BAK` 的名稱存在。
- 另外有 9 個呼叫在原版也找不到（非本次翻譯造成），本工具**不處理**
  （例：`クエスト：討伐報酬`、`ダンジョン：リーゲル神殿`、`Hイベント：テスト`）。
- 有 8 個翻譯後的呼叫名稱在名稱表中存在（定義端也被翻譯），本工具**不處理**
  （例：`名前変更`→`變更名字`、`肌色変え`→`改變膚色`、`錬金屋`→`鍊金工房`）。
- 不需要讀取或修改玩家存檔。

## 修改方法

採「還原呼叫端」：

- 只修改 `Data/MapData/` 下 18 個 `.mps` 的 23 個呼叫目標字串，改回原版日文名稱。
- **不修改** `Data/BasicData/CommonEvent.dat`。
- 修改後，呼叫端名稱與定義端名稱一致，CALL 可以正常解析。

## 環境

- 遊戲：`072project_Wings of Roldea_TC`（繁中 v1.21）。
- 系統：Windows + Windows PowerShell 5.1（`fix.bat` 會呼叫 `powershell`）。

## 使用

雙擊 `fix.bat`，依選單操作：

```
0 - 取消
1 - 安裝修復（先 dry-run 預覽，再確認）
2 - 卸載修復（還原安裝前的備份）
3 - 檢查目前狀態（不改檔）
```



## 還原與備份位置

- 備份：`solutions/backup/<時間>/pre-fix/Data/MapData/...`
- 紀錄：`solutions/backup/<時間>/pre-fix/manifest.json`
- 卸載：執行 `fix.bat` 選 `2`，會使用最近的備份還原。



## 驗證

安裝後可執行：

```bat
fix.bat -Action verify
```

預期顯示「沒有發現需要修復的呼叫點」。然後重新啟動遊戲，回到原本無法對話的偵探處確認。



## 注意

- 本工具是為 v1.21 的檔案狀態設計的。若遊戲版本不同、或 `Data/MapData - BAK` 已被移除
  
- 只處理「呼叫端被翻譯、定義端仍是日文」這一類；其他原版即存在的缺漏不在範圍內
